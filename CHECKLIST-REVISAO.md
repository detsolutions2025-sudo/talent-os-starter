# Checklist de revisão

Use esta lista após cada entrega da IA.

## Funcionamento

- [ ] O sistema abre.
- [ ] Não aparecem erros.
- [ ] Os testes passam.
- [ ] A documentação explica como executar.

## Segurança

- [ ] Não existem senhas no código.
- [ ] Não foram usados dados reais.
- [ ] A empresa está presente nos dados de negócio.
- [ ] Existem testes de acesso entre empresas.
- [ ] A IA não recebeu acesso à produção.

## Qualidade

- [ ] A alteração foi pequena.
- [ ] Os arquivos alterados foram listados.
- [ ] A IA explicou o que fez.
- [ ] A documentação foi atualizada.
- [ ] Não foram instaladas bibliotecas sem justificativa.
