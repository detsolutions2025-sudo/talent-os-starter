# Desenvolvimento com IA

## Processo

1. Ler documentação.
2. Escolher uma tarefa pequena.
3. Explicar o plano.
4. Definir critérios de aceite.
5. Implementar.
6. Criar testes.
7. Executar verificações.
8. Explicar o resultado.
9. Atualizar documentação.

## Tamanho recomendado

Uma tarefa deve caber em uma revisão humana simples.

Evite solicitações como:

> Desenvolva todo o sistema.

Prefira:

> Desenvolva a Fase 0, sem criar módulos de negócio. Antes de alterar arquivos, apresente o plano e aguarde apenas a revisão dentro da própria tarefa.
