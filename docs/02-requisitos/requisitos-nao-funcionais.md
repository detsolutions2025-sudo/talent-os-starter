# Requisitos não funcionais

## Segurança

- Separação entre empresas.
- Permissões verificadas no servidor.
- Auditoria.
- Criptografia.
- Proteção contra abuso.
- Segredos fora do código.

## Desempenho

- Paginação.
- Consultas limitadas.
- Processamento pesado em segundo plano.
- Monitoramento de erros e lentidão.

## Disponibilidade

- Backups.
- Teste de restauração.
- Serviços sem estado quando possível.
- Tratamento de falhas externas.

## Usabilidade

- Interface clara.
- Linguagem simples.
- Fluxos guiados.
- Mensagens de erro compreensíveis.
