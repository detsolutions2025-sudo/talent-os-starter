# Constituição de segurança

REGRA-001: Nenhuma consulta de negócio ocorre sem empresa definida.

REGRA-002: Todo endpoint autentica, autoriza e valida o vínculo do usuário.

REGRA-003: Identificadores enviados pelo navegador não provam propriedade.

REGRA-004: IA não toma decisão automática de contratação.

REGRA-005: Segredos não entram em código, prompt, log ou teste.

REGRA-006: Alterações críticas geram auditoria.

REGRA-007: Toda funcionalidade possui critérios de aceite e testes.

REGRA-008: Migrações destrutivas não são automáticas.

REGRA-009: Desenvolvimento não utiliza dados reais.

REGRA-010: Agentes não acessam produção.

REGRA-011: Toda análise de IA registra origem, versão e data.

REGRA-012: Dados de empresas diferentes nunca compartilham contexto de IA.
