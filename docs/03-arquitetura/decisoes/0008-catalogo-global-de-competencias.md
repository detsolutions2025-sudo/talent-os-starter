O Talent OS terá uma biblioteca global de competências.
Apenas o Platform Admin pode gerenciar essa biblioteca.
Empresas podem importar competências globais.
Empresas podem criar competências próprias.
Competências importadas não podem ser editadas pela empresa.
Competências nunca são excluídas fisicamente.
A competência é reutilizada por cargos, vagas, entrevistas, IA e outros módulos.
Toda referência futura deve usar o ID interno da competência, nunca o nome.
