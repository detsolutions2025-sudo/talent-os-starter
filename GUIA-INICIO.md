# Guia de início

Este arquivo foi escrito para quem não é profissional de desenvolvimento.

## O que você precisa fazer

### Etapa 1 — Criar uma pasta para o projeto

Crie uma pasta chamada:

`talent-os`

### Etapa 2 — Colocar estes arquivos dentro dela

Extraia o conteúdo deste pacote na pasta do projeto.

### Etapa 3 — Abrir no VS Code ou Antigravity

No VS Code:

1. Abra o programa.
2. Clique em **Arquivo**.
3. Clique em **Abrir Pasta**.
4. Escolha a pasta `talent-os`.

### Etapa 4 — Conectar a IA da IDE

Use a ferramenta de IA disponível na IDE.

Antes de pedir qualquer código, envie:

> Leia completamente os arquivos README.md, AGENTS.md, SECURITY.md e docs/00-visao/roadmap.md. Não escreva código ainda. Resuma o que entendeu, liste os riscos e proponha o plano apenas para a Fase 0.

### Etapa 5 — Não aceitar desenvolvimento de tudo de uma vez

A IA deve trabalhar em pequenas fases.

Ordem:

1. Preparar o projeto
2. Criar login e empresas
3. Garantir separação entre empresas
4. Criar DNA organizacional
5. Criar cargos
6. Criar vagas
7. Criar candidatos
8. Criar processo seletivo
9. Integrar IA
10. Criar relatórios

### Etapa 6 — Regra de aprovação

Antes de avançar de uma fase para outra, confirme:

- o sistema abre;
- os testes passam;
- não há erros visíveis;
- uma empresa não acessa dados de outra;
- existe uma explicação simples do que foi feito;
- os arquivos alterados estão listados.

## O que nunca fazer

- Não fornecer senha real para a IA.
- Não conectar banco de produção.
- Não permitir exclusão automática de dados.
- Não permitir publicação direta em produção.
- Não aceitar uma grande quantidade de código sem testes.
- Não copiar dados reais de candidatos para testes.
