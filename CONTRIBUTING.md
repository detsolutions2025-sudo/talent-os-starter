# Padrão de contribuição

## Para cada alteração

1. Descreva o problema.
2. Defina o resultado esperado.
3. Liste os critérios de aceite.
4. Crie ou atualize testes.
5. Faça uma alteração pequena.
6. Revise segurança e separação entre empresas.
7. Atualize a documentação.

## Nome de tarefas

Use o padrão:

`MODULO - ação objetiva`

Exemplos:

- `EMPRESAS - criar cadastro`
- `CARGOS - adicionar competências`
- `SEGURANÇA - testar isolamento`
